# Delivery Chat Documentation

Delivery Chat is a multi-tenant chat support platform. Embed a customizable chat widget on your website, and your team handles every conversation from a single admin dashboard — with real-time delivery, per-application configuration, and an optional AI Assistant that answers from your own data.

New here? Start with [Getting Started](/v1), then pick the integration that fits your stack.
